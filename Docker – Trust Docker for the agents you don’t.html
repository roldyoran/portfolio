Treinta estudios sobre fondo negro, cada uno con su propio movimiento. Solo se animan cuando están en pantalla.

Dónde encontrar más animaciones

Ocho sitios con demos, librerías y código abierto para seguir explorando.

  • particles.jsLa librería clásica de fondos de partículas, con un generador visual para configurarlas.vincentgarreau.com ↗
  • tsParticlesSucesora moderna de particles.js, con muchos presets, plugins y un editor en línea.particles.js.org ↗
  • Three.js · ejemplosCientos de demos WebGL; busca las de puntos y partículas para efectos 3D.threejs.org ↗
  • CodePen · particlesMiles de demos en HTML, CSS y JS que puedes abrir, leer y editar.codepen.io ↗
  • CodropsTutoriales y demos de efectos con canvas y WebGL, con el código explicado.tympanus.net ↗
  • ShadertoyEfectos creados con shaders, ideales para partículas y campos de luz complejos.www.shadertoy.com ↗
  • p5.js · ejemplosEjemplos de arte generativo y sistemas de partículas, fáciles de leer y modificar.p5js.org ↗
  • Vanta.jsFondos animados listos para usar (nubes, redes, ondas) con unas pocas líneas.www.vantajs.com ↗
